# Relógio Digital

Este projeto consiste em um relógio digital desenvolvido com HTML, CSS e JavaScript. Ele exibe a hora atual em tempo real, com um design simples e funcional.

## Tecnologias Utilizadas

- **HTML5**: Estruturação do conteúdo da página.
- **CSS3**: Estilização e layout do relógio.
- **JavaScript**: Lógica para atualização dinâmica da hora.

## Estrutura do Projeto

A estrutura de diretórios do projeto é a seguinte:

```
/
├── assets/
│   └── [arquivos de mídia, se houver]
├── index.html
└── README.md
```

- **assets/**: Contém arquivos de mídia utilizados no projeto (caso existam).
- **index.html**: Arquivo principal que contém a estrutura do relógio digital.
- **README.md**: Arquivo de documentação do projeto.

## Funcionalidades

- Exibe a hora atual em horas, minutos e segundos.
- Atualização em tempo real a cada segundo.

## Como Executar o Projeto

1. **Clone o repositório**:

   ```bash
   git clone https://github.com/WTC13/relogio-digital.git
   ```

2. **Navegue até o diretório do projeto**:

   ```bash
   cd relogio-digital
   ```

3. **Abra o arquivo `index.html`** no seu navegador preferido para visualizar o relógio digital.
